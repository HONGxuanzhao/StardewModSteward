# 验证范围

## v1.1.0

- 在 Windows 11 x64、Python 3.13.9、PySide6 6.9.2、requests 2.32.5 环境验证。
- 35 项核心与界面测试通过，覆盖自动发现多个 Steam 库、无效路径回退、更新键过滤、部分来源错误、组件/主包版本分离、已知修复版识别、缓存失效，以及安装、备份、配置保留、回滚、路径穿越、游戏进程阻止修改与启停。
- 安装、回滚及破坏场景测试均使用临时目录中的假游戏，不用真实存档作为测试目标。
- 实际本地目录探测成功，并对 101 份清单（99 个不同 ID）完成联网查询。修正前 17 行显示查询失败，修正后整项查询失败为 0；失效来源的原始错误仍保留在详情。此结果是一个安装快照，不是对所有用户的保证。
- 桌面 EXE 已实际启动并完成联网检查；在 PATH 不含 Python/Anaconda 的条件下完成打包程序启动与界面渲染验证。
- 已装版本号与非官方修复记录一致，仅表示版本匹配；不能替代游戏内验证。

## 尚未验证 / 不支持的边界

- 没有用真实 Nexus Premium API Key 验证完整下载授权与下载链路。请求和候选匹配代码已实现，真实账号权限、下载包内容与网络仍可能影响结果。
- 不宣称全部 MOD 的运行、数值、多人联机或旧存档兼容性已经验证。
- Linux、macOS、自定义 `--mods-path`、非标准 7-Zip 安装位置，以及原文件覆盖 MOD 不在当前支持范围。
- 没有把用户的 MOD 列表、账号密钥、游戏日志和检查缓存放入仓库。README 截图使用临时演示数据。

## 自行运行测试

```powershell
python -m pip install -r requirements.txt
python -m unittest -v test_core test_ui
```

不存在标准位置 7-Zip 的环境会跳过相应的解压测试。DPAPI 仅在 Windows 上验证。测试通过也不表示已执行真实 Nexus 授权下载。
